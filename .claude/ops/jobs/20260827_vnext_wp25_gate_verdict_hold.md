# WP2.5 게이트 판정 (2026-08-27, Claude) — **조건부 / S1–S4 보류**

실행 자체는 지시서 충실 이행이다(221쌍 전수 2인+조정, validator 80/80, 표본 동결·
사후 교체 0, 유료 0, HTTP 823 실패 0). 아래는 결과 **해석**에 대한 판정이다.

## 확정 수용 — S5

S5 36건 전수 `different`, `same` 0. **R1의 ≥6년 규칙 PASS 확정.** F-B(신규 거절 36건)
우려는 해소됐다. 플래그부 754쌍을 측정 모집단에서 배제한 정책도 타당하며 유지한다.

## 보류 — S1~S4의 100%

`bulk_candidate` 등급을 승인하지 않는다. 근거는 계측기 감도 의심이다.

1. **알려진 오류가 측정 모집단 안에 있다.** N100 core A70의 비-same 4쌍을 v4에서 조회한
   결과, **3쌍이 무플래그**이며 WP2.5가 측정한 밴드에 그대로 들어 있다
   (`other_anchor_3plus` 2쌍 — 둘 다 eligible=1, `anchor_2` 1쌍). 나머지 1쌍만
   `fanout_review_required`로 정당히 배제됐다. 즉 S2/S3 모집단은 "오류가 없는 모집단"이
   아니다.
2. **통계적 비정합.** 무플래그 오류율을 A70 기준 약 4%로 보면 160쌍 연속 무오류 확률은
   약 10⁻³다. 우연으로 설명하기 어렵다.
3. **라벨 사용 패턴.** WP2.5는 221행에서 `related` 0건·`insufficient` 0건을 냈다.
   S5에서 `different`는 36건 썼으므로 "다름"은 구분하지만, **중간 두 라벨을 한 번도 쓰지
   않았다.** N100은 같은 2인+조정 구조에서 core에만 related 1·insufficient 3, 전체
   불일치 20건을 냈다.
4. **놓친 3쌍의 성격이 일관된다** — 전부 척도·비교가능성 판단이다:
   구성요소 대 상위 프로젝트(Silhouette 리조트 일부인지 전체인지), 컴포넌트 대 우산
   프로젝트(Caravanserai ↔ Hello Wood Village '17), 한쪽이 도면뿐이라 물리적 비교 불가.
   사진과 이름이 맞으면 `same`으로 수렴하고 척도를 따지지 않는 계측기의 전형적 실패다.

## 원인 가설 (검증 대상)

N100 리뷰어는 축별 구조화 rationale(`image=/name=/firm=/place=/year=/scope=/basis=`)을
강제로 채웠다. **`scope=` 필드가 구성요소·단계 관계를 드러내는 강제 장치였다.**
WP2.5 form은 `r1_label`/`r2_label` + 자유 서술 `rationale` 구조로 보인다. 축 필드가
빠졌다면 그것이 중간 라벨 소실의 직접 원인이다.

## 처분

- S1~S4 등급은 **void가 아니라 보류**다. WP2.6 계측기 교정 probe 통과 시 그대로 유효.
- probe FAIL 시 S1~S4는 무효화하고, form 복원 후 **fresh disjoint 표본으로 재측정**한다
  (같은 표본 재사용 금지 — 이미 노출됨).
- 어느 경우에도 이번 결과만으로 일괄 승인 티어를 사용자에게 상정하지 않는다.
